# VNAGY Framework — Diagram Index (Monochrome Standard v1.0)

This directory contains the official monochrome diagrams used across the VNAGY Framework.  
All visuals follow deterministic layout rules, minimal component surfaces, and offline‑first reproducibility.

## Diagram Set
- VNAGY Tech Stack
- VNAGY MITRE Signal Flow
- VNAGY System Overview
- VNAGY Multi‑Role Architecture
- VNAGY Pseudo‑Heuristics
- VNAGY Secure‑First Architecture
- VNAGY Coding Standard Structure

## Standard Rules
- Color palette: #000000 / #333333 / #FFFFFF / #666666  
- Uniform line thickness (1.5 px)  
- No gradients, shadows, or dynamic elements  
- Explicit module boundaries  
- Inter font family (Regular, Medium, Bold)
