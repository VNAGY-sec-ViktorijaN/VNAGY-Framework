# logo-assets/

This directory contains all visual assets used across VNAGY installers, desktop environments, mobile applications, and core brand identity.  
It provides a structured, platform‑specific collection of icons, logos, splash screens, progress bar visuals, and UX/UI screen flows.

The contents of this directory are design assets only.  
No executable code or implementation logic is stored here.

All files in this directory — including PNG, SVG, ICO, and all UX/UI design documents — are protected under the **VNAGY Visual Asset License (2026)**.  
The full license text is available in the `LICENSE/` directory.  
This license prohibits unauthorized redistribution, modification, or commercial use of any visual asset contained here.

## Purpose

The `logo-assets/` directory standardizes all graphical elements used in VNAGY products.  
It ensures consistency across platforms by providing:

- installer logos and splash screens  
- desktop icons  
- mobile application icons  
- core brand identity files (color palette, typography, spacing grid)  
- installer UX/UI screen flows  

These assets define the visual appearance of VNAGY software and must be used as‑is unless explicitly permitted by the license.
