# VNAGY Color Palette
Minimal, deterministic, and security‑oriented brand palette.

---

## Primary Color

### Black
- HEX: #000000
- RGB: 0, 0, 0
- CMYK: 0, 0, 0, 100
- HSL: 0°, 0%, 0%

Used for:
- primary logo
- typography
- security diagrams
- UI elements requiring maximum contrast

---

## Contrast / Negative Space

### White
- HEX: #FFFFFF
- RGB: 255, 255, 255
- CMYK: 0, 0, 0, 0
- HSL: 0°, 0%, 100%

Used for:
- background
- negative space
- inverted monochrome logo

---

## Monochrome Variants

### Pure Black
Used for monochrome logo on light backgrounds.

### Pure White
Used for monochrome logo on dark backgrounds.

---

## Usage Rules

- VNAGY brand is strictly monochrome.
- No accent colors.
- No gradients.
- No transparency.
- All brand elements must use pure black or pure white.
- Backgrounds must maintain minimum 4.5:1 contrast ratio.

---

## Philosophy

The VNAGY palette reflects:
- offline‑first security engineering  
- deterministic visual identity  
- minimalism  
- high contrast  
- technical clarity
