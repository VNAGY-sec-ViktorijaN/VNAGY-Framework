# VNAGY Spacing & Grid Specification
Deterministic, minimal, and structurally predictable spacing system.

---

## Core Principles

VNAGY spacing follows strict rules:
- deterministic geometry  
- no arbitrary padding  
- no decorative spacing  
- predictable alignment  
- consistent proportional ratios  

Spacing exists only to preserve clarity and structural readability.

---

## Base Unit

### 8‑Point Grid System
All spacing values must be multiples of **8 px**.

Examples:
- 8 px  
- 16 px  
- 24 px  
- 32 px  
- 40 px  
- 48 px  

No fractional values.  
No irregular spacing.

---

## Layout Structure

### 1. Margins
- Outer margins: **32 px**  
- Internal section margins: **24 px**  
- Minimal safe margin: **16 px**

Margins must remain consistent across all VNAGY brand‑core assets.

### 2. Padding
- Component padding: **16 px**  
- Text block padding: **12–16 px**  
- Logo padding: **24 px** minimum

Padding must never exceed 2× the base grid unit.

---

## Alignment Rules

### 1. Left Alignment (Default)
All documentation, UI text, and technical content must be left‑aligned.

### 2. Center Alignment (Restricted)
Center alignment is permitted only for:
- VNAGY logo  
- brand‑core identity elements  
- title pages  

No other components may use center alignment.

### 3. No Justification
Text justification is prohibited due to unpredictable spacing artifacts.

---

## Logo Spacing Rules

### Primary Logo
- Minimum clear space: **48 px** around all sides  
- No overlapping elements  
- No compression or stretching  
- Logo must remain optically centered

### Minimal Logo
- Minimum clear space: **40 px**  
- Same geometric constraints as primary logo

### Monochrome Logo
- Minimum clear space: **48 px**  
- Must remain visually identical to primary logo except for color

---

## Grid Ratios

VNAGY uses deterministic ratios:
- **1 : 1** for square elements  
- **1 : 2** for vertical blocks  
- **2 : 1** for horizontal blocks  

No irregular ratios.  
No freeform layout.

---

## Component Spacing

### Headings
- H1 → 32 px top / 24 px bottom  
- H2 → 24 px top / 16 px bottom  
- H3 → 16 px top / 12 px bottom  

### Paragraphs
- Paragraph spacing: **16 px**  
- Line height: **1.25×**

### Lists
- Item spacing: **8 px**  
- List block spacing: **16 px**

---

## Visual Consistency Rules

- No overlapping layers  
- No floating elements  
- No asymmetrical spacing  
- No decorative whitespace  
- All spacing must follow the 8‑point grid
