# VNAGY Typography Specification
Minimal, deterministic, and security‑oriented typographic standard.

---

## Primary Typeface

### Winner Sans Wide Extra Bold
Used for:
- VNAGY logotype
- primary headings
- brand‑core identifiers
- high‑contrast security labels

Characteristics:
- wide geometry
- high legibility
- strong monolithic presence
- suitable for monochrome brand identity

---

## Secondary Typeface

### Inter (Regular / Medium / Bold)
Used for:
- documentation
- UI text
- technical descriptions
- module specifications

Characteristics:
- neutral and modern
- optimized for screen readability
- consistent across platforms

---

## Typographic Rules

### 1. Monochrome Only
All text must use pure black (`#000000`) or pure white (`#FFFFFF`).
No gradients, no color accents.

### 2. No Decorative Typography
No italics, no script fonts, no stylistic alternates.
Typography must remain functional and technical.

### 3. Deterministic Hierarchy
- H1: Winner Sans Wide Extra Bold  
- H2: Inter Bold  
- H3: Inter Medium  
- Body: Inter Regular  

Hierarchy must remain consistent across all VNAGY materials.

### 4. Spacing Rules
- Line height: 1.25×  
- Paragraph spacing: 1× line height  
- No excessive padding  
- No compressed text blocks  

Spacing must preserve clarity and structural readability.

### 5. Alignment Rules
- Left‑aligned for documentation  
- Center‑aligned only for logotype and brand‑core assets  
- No justified text  

Alignment must remain predictable and minimal.

---

## Usage Contexts

### Brand‑Core Assets
- Winner Sans Wide Extra Bold  
- Monochrome  
- High contrast  
- Used in logos, splash screens, installers

### Technical Documentation
- Inter Regular / Medium / Bold  
- Strictly monochrome  
- No marketing tone  
- No decorative formatting

### UI Elements
- Inter  
- Consistent sizing across platforms  
- Minimum 4.5:1 contrast ratio
