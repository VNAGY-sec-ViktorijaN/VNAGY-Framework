# VNAGY Mobile Asset Directory

This directory contains platform‑specific graphical assets for the VNAGY Framework.
Assets follow deterministic sizing rules, adaptive icon specifications, and
cross‑platform mobile design standards.

## Structure
- android/
  - Adaptive icon foreground/background layers
  - Density‑scaled launcher icons (mdpi → xxxhdpi)
  - Splash screen assets (mdpi → xxxhdpi)
  - Adaptive icon XML declaration
- ios/
  - iOS icon set (all required sizes)
  - iOS splash screen assets

## Purpose
Provide a complete, pre‑scaled, platform‑ready asset set for future mobile
integration. Assets are prepared independently of implementation code and may be
directly copied into Android or iOS project structures.
