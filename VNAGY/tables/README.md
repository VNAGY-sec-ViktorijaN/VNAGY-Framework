# VNAGY Framework — Tables Directory (Monochrome Standard v1.0)

This directory contains the official tabular specifications used across the VNAGY Framework.  
All tables follow deterministic structure, explicit module boundaries, and offline‑first reproducibility.

## Included Tables
- VNAGY Pseudo‑Heuristics Table  
- VNAGY Multi‑Role Architecture Table  
- VNAGY Compliance Mapping Table  

Each table is provided in monochrome format and aligned with VNAGY structural rules.

## Standard Rules
- Color palette: #000000 / #333333 / #FFFFFF  
- Uniform line thickness (1.5 px)  
- No gradients, shadows, or dynamic elements  
- Inter font family (Regular, Medium, Bold)  
- Deterministic layout with minimal component surfaces  

## Purpose
These tables serve as structural references for:
- Security architecture documentation  
- Offline‑first system modeling  
- Academic research  
- Whitepaper inclusion
